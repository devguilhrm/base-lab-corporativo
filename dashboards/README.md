# Dashboards

Este diretorio guarda a estrategia de paineis Grafana do projeto.

## Dashboards alvo do roadmap

- Linux Health
- Active Directory Health
- Network Traffic (SNMP)
- SLA and Uptime (executivo)
- Capacity Planning

## Fonte inicial

- Dashboard de exemplo provisionado: `infra/grafana/dashboards/linux-health.json`

## Recomendacao

1. Importar dashboards comunitarios do Grafana Labs.
2. Clonar para versoes customizadas do lab.
3. Versionar JSON final neste diretorio com nome:
   - `linux-health-v1.json`
   - `ad-health-v1.json`
   - `network-snmp-v1.json`
